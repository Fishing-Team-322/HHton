# Крейт `storage`

Фасад над S3‑совместимым хранилищем для артефактов отправок:
- Структуры `SnapshotMetadata` и `Snapshot` описывают метаданные и содержимое архива решения.
- `ObjectStorage` управляет ключами (архив, метаданные, произвольные артефакты), поддерживает префиксы и предоставляет методы `upload_snapshot`, `get_snapshot`, `put_artifact`, `get_artifact`, `list_artifacts`.
- Метаданные сериализуются в JSON и сохраняются рядом с архивами; все операции логируются и аннотируются трейсингом.

Крейт рассчитан на работу с клиентом `aws-sdk-s3`; для локальной разработки можно указывать адрес MinIO через стандартные переменные окружения AWS.
