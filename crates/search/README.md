# Крейт `search`

Минимальный слой для разбора поисковых запросов:
- `SearchQuery::parse` нормализует ввод пользователя, удаляя пустые строки и приводя к нижнему регистру.
- `SearchQuery::tokens` превращает запрос в набор алфавитно-цифровых токенов, отбрасывая пробельные и пунктуационные символы.
- `parse_many` позволяет валидировать пакет запросов с привязкой контекста ошибок.

Модуль не содержит реального индекса; он предназначен для будущей интеграции с движком поиска (например, Tantivy или внешним SaaS).
