# Крейт `persistence`

Слой доступа к данным и миграциям. Основные элементы:
- Обёртка `Database` над пулом `sqlx::PgPool` с трейсингом при инициализации и доступом к пулу через метод `pool()`.
- Каталог `migrations/` предназначен для SQL‑миграций.
- В `repositories/` можно размещать реализации хранилищ для доменных агрегатов.

На данный момент крейт задаёт структуру для подключения к PostgreSQL; реальная логика репозиториев должна быть добавлена позже.
