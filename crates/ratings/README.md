# Крейт `ratings`

Алгоритмы подсчёта рейтингов участников и команд:
- `Rating` хранит балл 0..=100, умеет нормализовать его в долю и усреднять при объединении.
- `parse_score` валидирует строковый ввод в рейтинг.
- `EventScale`, `EventOutcome` описывают масштаб и результаты события; есть конвертация из protobuf‑контрактов и валидация входных данных (позиция, количество участников, корректность дат).
- `RatingFactors` задают конфигурацию весов: базовый множитель, влияние позиции, вес масштаба, штраф за размер команды и затухание по времени.
- `ParticipantProfile` и `LeaderboardEntry` описывают агрегированные результаты для внешних систем.

Крейт служит ядром для сервисов рейтинга и может быть расширен новыми алгоритмами агрегации или сериализацией профилей.
