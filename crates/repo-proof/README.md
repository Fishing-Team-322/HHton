# Крейт `repo-proof`

gRPC‑клиент и минимальная серверная реализация проверки привязки репозитория:
- `RepoProofClient` выполняет `health_check` и `verify_binding`, проксируя запросы к удалённому сервису.
- `RepoProofServiceHandler` — встроенный сервер, отвечающий на health‑check и оценивающий привязку по набору простых правил (поддерживаемый провайдер, формат `owner/repo`, хеш коммита).
- Функции `service()` и `serve()` помогают поднять gRPC‑сервер с внешним сигналом завершения.

Валидация сохраняет в вердикте собранные поля запроса и помечает исход с временной меткой, что можно использовать для трассировки или аудита.
