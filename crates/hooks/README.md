# Крейт `hooks`

Простой механизм для уведомлений о событиях жизненного цикла:
- `emit(event)` публикует событие в логах через `tracing`.
- `register(subscriber)` служит заглушкой для регистрации внешних подписчиков.

Код сейчас выполняет только логирование; в дальнейшем сюда можно добавить интеграцию с очередями, вебхуками или брокерами событий.
