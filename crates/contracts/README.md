# Крейт `contracts`

Набор protobuf/gRPC контрактов, из которых генерируется клиентский и серверный код (через `tonic-build`). Включает пять служб:
- `participants` — управление участниками и командами.
- `events` — операции с хакатонами и расписанием.
- `submits` — загрузка решений и статусов проверки репозитория.
- `rating` — обновление рейтинга участника по результатам событий.
- `repo_proof` — проверка привязки репозитория.

В `src/lib.rs` модули подключаются через `tonic::include_proto!`, а тесты убеждаются, что клиенты можно создать и что ключевые сообщения содержат новые поля для дедлайнов, статусов и исходов событий. Если протоколы расширяются, достаточно добавить файлы в `proto/` и обновить сборку.
