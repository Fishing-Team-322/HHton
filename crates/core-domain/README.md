# Крейт `core-domain`

Содержит предметные модели и доменные службы, которые описывают бизнес-правила хакатонной платформы:
- **`model`** — трейт `AggregateRoot` и тип `EntityId` для унифицированной идентификации агрегатов.
- **Модели**: `hackathon`, `team`, `user`, `submission`, `rating` описывают поля и инварианты сущностей (название/описание хакатона, дедлайны, лимит размера команды, состав команды, связки отправок и репозиториев).
- **`application`** — вспомогательные типы для пользовательских команд и запросов (DTO слоя приложения).
- **`services`** — правила, проверяющие инварианты: открыто ли окно регистрации/подачи, не превышен ли лимит команды, может ли участник присоединиться и т. д.; функции возврашают `Result` с ошибкой инварианта.

В корневом модуле определена функция `validate_invariant`, упрощающая проверку бизнес-ограничений. Тесты покрывают дедлайны регистрации/подачи, запрет двойного вступления в команду и соблюдение лимита участников.
