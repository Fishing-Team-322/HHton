# Крейт `hackcore-server`

Основной gRPC‑сервер платформы. Состоит из нескольких модулей:
- `config` — загрузка конфигурации (PostgreSQL, S3, repo-proof, порты) через `config` и переменные окружения.
- `telemetry` — настройка `tracing` и форматирования логов.
- `persistence` — адаптеры для подключения к слою `persistence` и запуска миграций.
- `services` — обработчики gRPC: участники, события, отправки решений, рейтинги. `SubmissionsService` объединяет доступ к БД, S3 (`storage`) и проверке репозитория (`repo-proof`).
- `main`/`lib` — инициализация зависимостей, запуск сервера на Unix‑сокете, graceful‑shutdown.

Крейт собирает все остальные компоненты, но бизнес-логика обработчиков пока минимальна. Следующий шаг — наполнить сервисы реальными операциями и валидировать входные данные.
